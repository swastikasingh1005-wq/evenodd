
# Even or Odd Checker

## Description
A simple JavaScript project that checks whether a given number is even or odd using an if-else statement.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Checks whether a number is even or odd.
- Uses if-else statements.
- Uses the modulus (%) operator.
- Displays the result on the webpage.
- Prints the result in the browser console.

## Logic
If a number is divisible by 2, it is even.
Otherwise, it is odd.

## How to Run
1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open index.html in your browser.
4. Enter a number and click Check Number.
